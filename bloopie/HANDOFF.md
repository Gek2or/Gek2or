# Bloopie — контекст для продолжения работы

Этот файл самодостаточен: его можно отдать новому ассистенту вместе с архивом
`bloopie-project.zip` или репозиторием `gek2or/gek2or` (ветка `ccr-4de81cc6-9tmkl3`).

## 1. Состояние

Переход на спецификацию v02 в части Godot завершён: голова ветки запускается, проверена
скриншотами всех экранов и автоматическим прогоном сценариев (тап, поглаживание, какао,
покупка шапочки, награда за вокал, сохранение). APK собирается командой из раздела 2.

Не сделано: бэкенд FastAPI + Gemini, реальный биллинг, локализация, растровый арт.

## 1a. Живописный арт (главное изменение)

Процедурная векторная графика заменена артом, вырезанным из утверждённых прототипов
(скриншоты экранов 1124×1998). Всё лежит в `art/painted/`:

| Файл | Что это |
| --- | --- |
| `room_supporter.jpg`, `room_explorer.jpg` | комнаты без Блупи и без интерфейса (дыры восстановлены) |
| `bloopie_body.png`, `bloopie_wizard.png` | Блупи с альфа-каналом: обычный и в шляпе волшебника |
| `face_laugh.png`, `face_sing.png` | накладки: смеющееся лицо и открытый поющий рот |
| `face_eyes_blank.png`, `face_brows_blank.png`, `face_mouth_blank.png` | плюш поверх глаз, бровей и рта — поверх них рисуется тушь |
| `icon_*.png` | иконки дока и панели заботы |
| `painted.json` | рамка спрайта в исходной картине и координаты лампочек гирлянды |

Как это собрано в игре:

- `SkyBackdrop` — `TextureRect` с картиной комнаты 1080×1920. Камера всегда масштабируется
  так, чтобы картина закрывала экран целиком (`MainRoom._cover_zoom()`): 1.0 на 9:16,
  около 1.25 на 20:9. За пределы картины камера не выходит.
- `BodyBase` — спрайт Блупи. Его положение и масштаб выставляет
  `BloopieActor._align_painted_layers()` по `painted.json`, поэтому пересборка арта не
  требует правок сцены.
- `FaceController` выбирает накладки под эмоцию; `FaceInk` (`BloopieArt.draw_face_ink`)
  дорисовывает тушью закрытые веки, выразительные брови, грустный / сердитый / удивлённый
  рот и канонический блок зубок.
- Темы: `palette_swap.gdshader` сдвигает оттенок голубого плюша к цвету темы; радужки
  глаз остаются синими (их эллипсы передаются в шейдер).
- Комната шутника пока использует картину комнаты спокойного друга.

Чего в живописи пока нет (нужны новые рендеры в том же стиле):

- шапочки `cosy`, `cat`, `frog` — рисуются кодом поверх спрайта и выбиваются из стиля;
- комната шутника; варианты окна «закат» и «ночь» (сейчас это цветокоррекция той же картины);
- купол крио-капсулы (рисуется кодом); отдельные позы для ходьбы, прыжка, игры с мячом
  (сейчас двигается и сплющивается один спрайт);
- Блупи повзрослее для Lv.10 и Lv.20 (сейчас тот же спрайт крупнее).

Лучший исходник для каждого такого рендера: тот же кадр и тот же Блупи, без интерфейса,
без подписи «Gemini has detected this screenshot», исходный файл, а не скриншот галереи.

## 2. Проект

- Godot 4.3, GDScript. Портрет 1080×1920. Главная сцена `scenes/MainRoom.tscn`.
- Графика — живописный арт из прототипов (`art/painted/`) плюс немного процедурной
  отрисовки поверх (тушь лица, эффекты эмоций, шапочки-капюшоны, купол). Звук синтезируется в коде.
- Бэкенда нет. `AIClient` шлёт `POST {bloopie/backend_url}/v1/interact`, при ошибке
  отвечает встроенными репликами по архетипу.

```
bloopie/
  project.godot, export_presets.cfg
  scenes/MainRoom.tscn
  scripts/autoload/   GameState, TimeWeatherSystem, AIClient, MemoryManager
  scripts/bloopie/    BloopieActor, BloopieArt, BloopiePart, FaceController,
                      BloopieVoiceSynth, ProcAudio
  scripts/environment/ EnvironmentController, RoomArt, FairyLightsDrawer
  scripts/ui/         UIStyle, CareDrawer, VocalMinigame, MemoryAlbum, Onboarding
  scripts/MainRoom.gd
  shaders/            rain_window.gdshader, palette_swap.gdshader
```

### Как устроен рендер Блупи

- `BloopieActor` держит общий словарь `state` (палитра, эмоция, моргание, взгляд, рот,
  стадия роста, шапочка, время).
- Каждый слой под `VisualRoot` — узел со скриптом `BloopiePart.gd` и полем `part`.
  Он вызывает соответствующую функцию `BloopieArt.draw_*`.
- Если узлу-слою назначить `texture` / `sprite_frames`, процедурная отрисовка этого
  слоя отключается — так вставляется готовый арт.
- Канон зубок — `BloopieArt.draw_teeth()`: один блок 30×19.5 px со скруглённым низом
  и единственной вертикальной линией. Вызывается из `draw_mouth()` для всех эмоций.

### Проверка без редактора

```
godot --headless --path bloopie --import          # импорт ассетов
godot --headless --path bloopie --quit-after 120  # дымовой запуск, ошибок быть не должно
xvfb-run -a godot --path bloopie --rendering-method gl_compatibility --rendering-driver opengl3 -s <скрипт.gd>   # скриншоты
```

Скрипт для скриншотов наследует `SceneTree`, загружает `MainRoom.tscn`, вызывает методы
сцены и сохраняет `root.get_texture().get_image()`. События касания подаются через
`Input.parse_input_event()`; координаты нужно умножать на `root.get_final_transform()`.

### Сборка APK

Нужны шаблоны экспорта Godot 4.3 (`android_debug.apk`), JDK, `apksigner` и debug-keystore;
пути задаются в Editor Settings → Export → Android.

```
godot --headless --path bloopie --export-debug "Android" build/bloopie-debug.apk
```

## 3. Канон персонажа (не нарушать)

- Круглое плюшевое тело `#8AC7F7`, пропорция 1.08 : 1.0, контур `#232946` (чёрный запрещён),
  контровой свет `#FFD175`.
- Спиральный завиток 1.5 оборота, хохолки по бокам из 2–3 долей, две овальные лапки снизу.
- Глаза: большие вертикальные овалы `#1E2542 → #8AC7F7`, реснички, блики, 4-конечные звёздочки.
- Румянец `#FF8FA3` с тремя штрихами `#E05772`.
- **Зубки:** ровно два верхних, на 25% меньше обычных, слиты в один белый блок `#FFFDF9`
  с одной тонкой вертикальной линией. Без щели, клыков и языка. Широко открытый рот
  допустим только на высокой ноте в вокальной игре.
- Подушка крупной вязки `#E6B39A`.

## 4. Что есть в игре (v02)

- **GameState** (`user://bloopie_save_v02.json`): `player_name`, `archetype`, `current_theme`,
  `current_hat`, `owned_hats`, `has_active_subscription`, `is_frozen`, `hunger`, `hygiene`,
  `energy`, `mood`, `vocal_level` (1–99), `affection_xp`, `pet_level` (1–20), `coins`,
  `recent_memories` (кольцо на 7), `album_cards` (`timestamp`, `date_string`, `caption`, `image_path`).
- **Без наказаний:** `hunger` и `hygiene` медленно снижаются, но не ниже 35; настроение не падает.
- **Монеты:** старт 120, подарок дня 20, +25 за уровень, за вокал `5 + точность / 5`.
  Какао 5, тарт 10. Шапочки: cosy 50, cat 120 (Lv.5), frog 200 (Lv.10), wizard 350 (Lv.20);
  первая кнопка предлагает цену, вторая покупает.
- **TimeWeatherSystem:** `current_time_of_day` (evening / sunset / night), `current_weather`
  (rain / stars), сигнал `environment_updated`. У исследователя окно всегда в звёздную ночь.
- **AIClient:** `Authorization: Bearer <bloopie/api_token>`, офлайн-ответы при любой ошибке.
- **MemoryManager:** `take_polaroid()` прячет HUD на кадр, снимает, даёт вспышку, пишет PNG и карточку.
- **Перекраска:** плюшевые слои рисуются в палитре `original`, тему задаёт `palette_swap.gdshader`
  (параметры `target_base` / `target_shade`, плавный переход 0.6 с).
- **Кадр:** `BloopieActor.scale = 1.5`, камера `(540, 960)` с масштабом «закрыть экран»;
  в чате приближение до 1.18 и док уступает место строке ввода с кнопкой «назад».
  Пузырь речи ужат до 0.75, чтобы текст остался UI-размера.
- **HUD:** плашки уровня и монет, шкала настроения, кнопка альбома; кремовый док на белой
  полупрозрачной рамке; панель заботы со шкалой «Счастье» и четырьмя плитками (какао, тарт,
  темы, шапочки); чистота восстанавливается во сне; альбом 2×2 с пагинацией;
  вокальная игра с бирюзовой волной и нотными кольцами (палец в любой точке экрана,
  зона управления — от 30% до 82% высоты); в стазисе док заменяет кнопка
  «Разбудить Блупи (Cozy Pass)».

## 5. Что осталось сделать

1. **Бэкенд FastAPI + Gemini 2.5 Flash.** Запрос: `message`, `player_name`, `archetype`, `stats`,
   `recent_memories`, `context`, `event`. Ответ: `reply_text`, `emotion_animation` (одна из 12 эмоций),
   `stat_deltas {mood_delta, energy_delta, affection_delta}`, `save_to_memory`.
2. **Биллинг** Google Play / StoreKit вместо `GameState.request_cozy_pass_purchase()`.
3. **Недостающий арт** — список в разделе 1a.
4. **Проверка на телефоне:** запуск под Vulkan, вибрация, клавиатура, звук.
5. **Локализация** (сейчас интерфейс и офлайн-реплики только на русском).

## 6. Решения и ограничения

- Интерфейс на русском; на макетах подписи английские. Локализации нет.
- Эмодзи заменены SVG-иконками: во встроенном шрифте Godot их нет.
- Погода симулируется от даты и часа, без геолокации.
- Покупка не подключена: в debug-сборке кнопка выдаёт подписку сразу, в release сообщает,
  что покупка недоступна.
- Renderer `mobile` требует Vulkan. В этом окружении Vulkan нет, поэтому проверка шла через
  `--rendering-method gl_compatibility`. Если APK не стартует на телефоне, вернуть в
  `project.godot` `renderer/rendering_method="gl_compatibility"`.
- APK ни разу не запускался на устройстве: проверены только подпись и состав пакета.
- Контроллы с нулевым размером отсекаются при зуме камеры — у `WindowFrameProps` задан
  размер 1080×1920 именно поэтому.
- Сообщение со спецификацией v02 оборвалось на дереве сцены; раздел про бэкенд не дошёл.
